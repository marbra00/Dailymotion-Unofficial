# Kodi-Official

Source for addons in Kodi Repository

## Dailymotion – Unofficial

An unofficial fork of gujal's Dailymotion addon, maintained independently by marbra00. This addon is not an official product of Dailymotion or Team Kodi.

- Addon ID: `plugin.video.dailymotion_unofficial`
- Version: `1.0.0`
- Licence: GPL-3.0-or-later; [licence text](plugin.video.dailymotion_unofficial/LICENSE)
- Original project: [Gujal00/Kodi-Official](https://github.com/Gujal00/Kodi-Official); original contributions remain in the Git history.
- Playback repair tested on Kodi 21.3 for Windows.

See the [German and English installation guide](plugin.video.dailymotion_unofficial/README.md) for ZIP installation, quality settings, dependencies and `.strm` links. Installable packages will be published under [Releases](https://github.com/marbra00/Kodi-Official/releases). GitHub's “Download ZIP” is a source archive, not an installable addon package.

## plugin.video.imdb.trailers

### Kodi Addon for playing trailers from IMDb website

![License](https://img.shields.io/badge/license-GPL--3.0--only-success.svg)
![Kodi Version](https://img.shields.io/badge/kodi-leia%2B-success.svg)
![Contributors](https://img.shields.io/github/contributors/Gujal00/Kodi-Official.svg)

Head to the [Forum for support](https://forum.kodi.tv/showthread.php?tid=352127)

You can also call this addon from other addons or in STRM files as below.
> plugin://plugin.video.imdb.trailers/?action=play_id&imdb=imdb_id

For example,

> plugin://plugin.video.imdb.trailers/?action=play_id&imdb=tt0113957
